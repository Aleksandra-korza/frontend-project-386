Задача [«Список типов встреч через всю цепочку»](https://github.com/Aleksandra-korza/frontend-project-386/issues/17), `docs/specs/home-page.md`.                                                                                                                  |
| OQ-05 | Сверить тексты карточки «Как устроена запись» на главной с реализованным поведением     | Тексты совпадают с поведением, не меняются: гость указывает только имя и email; окно — 14 дней с завтрашнего (`buildSchedule`); слоты 09:00–18:00 по `Europe/Warsaw` во все дни недели; пересечения с бронированиями любых типов проверяет сервер (`409 SLOT_TAKEN`, ADR-0003). Задача [«Создание бронирования»](https://github.com/Aleksandra-korza/frontend-project-386/issues/21). |
| OQ-04 | Согласование термина «запись» в FR-20…FR-22 `docs/requirements.md`                      | «Запись» в значении бронирования заменена на «бронирование» в FR-20 и FR-22 (FR-21 термин не использует); раздел «Неоднозначности» удалён из `GLOSSARY.md`. «Запись» остаётся названием процесса (глоссарий, Q13). Задача [«Предстоящие бронирования владельца»](https://github.com/Aleksandra-korza/frontend-project-386/issues/22).                                                 |
| OQ-07 | Fallback на `index.html` для клиентских адресов при раздаче собранного frontend         | Fastify отдаёт `index.html` для адресов вне `/api` без файла; `/api/*` без маршрута — JSON 404. ADR-0006, `docs/specs/deploy.md` §2, задача [#27](https://github.com/Aleksandra-korza/frontend-project-386/issues/27).                                                                                                                                                                |
