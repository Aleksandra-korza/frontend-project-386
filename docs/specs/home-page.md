# Спецификация: главная страница

> Статус: согласовано 2026-11-20 по итогам интервью (вопросы Q1–Q25). Реализация — после отдельного подтверждения.
> Термины — `GLOSSARY.md`; архитектурные решения — `docs/adr/0001`, `docs/adr/0002`; открытые вопросы — `docs/open-questions.md`.

## Назначение и аудитория

- Главная страница адресована **гостю**; ссылок на раздел владельца `/admin` нет (Q1; D-11, SEC-01).
- Цель — за несколько секунд объяснить, что это сервис записи на встречу, и привести гостя к одному действию — «Записаться» (Q2).
- Название в интерфейсе — «Календарь звонков» (Q3).

## Маршруты

| Адрес     | Страница                                              | Решение           |
| --------- | ----------------------------------------------------- | ----------------- |
| `/`       | Главная страница                                      | Q14               |
| `/book`   | Страница записи — каталог типов встреч; пока заглушка | Q7, Q14, ADR-0002 |
| остальные | «Страница не найдена»                                 | Q15               |

Адреса следующих шагов записи (день, время, подтверждение) определяются на этапе бронирования.

## Общая шапка

- Логотип: иконка `CalendarClock` (lucide, оранжевая) и надпись «Календарь звонков»; ведёт на `/` (Q6, Q19).
- Навигация — один пункт «Записаться» → `/book`; на `/book` пункт подсвечен, на главной не подсвечено ничего (Q6, Q18).
- Пункта «Предстоящие события» нет (D-11).

## Главная страница (`/`)

Структура повторяет демо (Q4; FR-23): слева текстовый блок, справа карточка.

- Плашка: «Быстрая запись на звонок».
- Заголовок: «Календарь звонков».
- Описание: «Выберите тип встречи, удобный день и свободное время — и запишитесь на звонок без регистрации.»
- Кнопка: «Записаться →», ведёт на `/book` (Q7).
- Карточка «Как устроена запись» (Q5, Q17):
  - без регистрации — достаточно имени и email;
  - свободное время на 14 дней вперёд, начиная с завтрашнего дня;
  - рабочие часы 09:00–18:00 по Варшаве (`Europe/Warsaw`), ежедневно, включая выходные;
  - занятое время забронировать нельзя — сервер проверяет пересечения.

Тексты карточки опираются на требования D-01…D-03, D-07, D-12, BR-14…BR-18 и описывают поведение, которое реализуется на этапе бронирования.

## Подвал: статус сервиса

Неприметная строка статуса сервиса в подвале, получаемая через сгенерированный SDK (`getHealth()`): «проверка…» / «доступен» / «недоступен». Сохраняет обращение frontend к API через SDK (TC-05, AC-27). Пересмотр Q11.

> **Убрана** (OQ-06, задача #17): каталог на `/book` обращается к API через SDK (`listMeetingTypes()`), поэтому TC-05/AC-27 выполняются без строки статуса. Подвала нет; `GET /api/health` остаётся в API для проверки готовности backend.

## Страница записи (`/book`) — заглушка

> **Заменена** каталогом типов встреч (задача #17): `docs/specs/booking.md` §6.1.

- Та же шапка; пункт «Записаться» подсвечен.
- Заголовок: «Запись на встречу».
- Текст: «Скоро здесь можно будет выбрать тип встречи, удобный день и свободное время. Запись пока недоступна.»
- Ссылка «На главную».
- Без форм, календаря и демо-данных (Q16).

## Страница «не найдено»

Заголовок «Страница не найдена» и ссылка на главную (Q15).

## Внешний вид

- Стиль демо: светлый фон с мягким сине-оранжевым градиентом, белые скруглённые карточки, оранжевый акцент кнопки — через переопределение `--primary`, без смены темы shadcn (Q9).
- Адаптивная вёрстка: на узком экране карточка уходит под текстовый блок (Q10).
- Только светлая тема, без переключателя (Q20).
- Шрифт Geist (Q21).
- Заголовки вкладки: «Календарь звонков»; «Запись — Календарь звонков»; «Страница не найдена — Календарь звонков». Favicon — иконка календаря вместо стандартной иконки Vite (Q19).

## Техническая реализация

- Маршрутизация — React Router, data mode (Q8, Q23; ADR-0001).
- Компоненты shadcn/ui `Button` и `Card` через `shadcn add`; остальное — Tailwind (Q22).
- Файлы frontend (Q25):
  - `src/pages/HomePage.tsx`, `src/pages/BookPage.tsx`, `src/pages/NotFoundPage.tsx`;
  - `src/components/SiteHeader.tsx`; компоненты shadcn — `src/components/ui/`;
  - `src/router.tsx` — список маршрутов;
  - `src/App.tsx` — макет: шапка, страница, подвал.

## Автоматические тесты

Пересмотр Q12: минимальные тесты страниц.

- Зависимости `apps/frontend` (devDependencies, точные версии): `@testing-library/react`, `happy-dom`. Без `jest-dom` и `user-event`.
- Окружение Vitest для проекта frontend: `environment: 'happy-dom'` в `apps/frontend/vite.config.ts`.
- Три теста на тех же маршрутах через `createMemoryRouter`:
  1. главная показывает название, описание и кнопку «Записаться», ведущую на `/book`;
  2. нажатие «Записаться» открывает страницу записи с заголовком «Запись на встречу»;
  3. неизвестный адрес показывает «Страница не найдена» со ссылкой на главную.
- Тесты входят в `mise run check` и CI без изменения workflow.
