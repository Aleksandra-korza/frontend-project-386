# Запись начинается с каталога типов встреч по адресу `/book`

Главная страница — отдельная страница с одним целевым действием «Записаться»; кнопка ведёт на `/book`, где начинается запись — с каталога типов встреч (путь гостя UC-03, AC-05: главная → тип встречи → дата → время → подтверждение). Каталог не встраивается в главную, чтобы главная объясняла сервис, а запись жила в своём разделе; пока бронирование не реализовано, на `/book` стоит заглушка, которую следующий этап заменит каталогом без изменения навигации. Адрес `/book` — английский и короткий, как `/admin`.

## Considered Options

- **Каталог прямо на главной** — меньше переходов, но смешивает объяснение сервиса и первый шаг записи.
- **Другие адреса** (`/booking`, `/types`, `/zapis`) — отклонены в пользу короткого `/book`, совпадающего с действием кнопки.

## Consequences

Главная сознательно отличается от демо (`docs/reference/`), которое служит лишь визуальным ориентиром (NFR-03):

- в гостевой навигации только «Записаться» — пункта «Предстоящие события» нет (D-11);
- название в интерфейсе — «Календарь звонков», а не «Calendar»;
- текст демо «фиксированные 30-минутные слоты» не используется: длительность задаёт тип встречи (D-04, D-14).
