# Реализация контракта на backend: ручные маршруты Fastify со схемами из OpenAPI

API описывается в TypeSpec (`api/main.tsp`), из него генерируется `api/generated/openapi.json`, а из OpenAPI — SDK frontend (`mise run codegen`). TC-06 требует использовать генерацию серверных типов и маршрутов, если стек её поддерживает. Backend регистрирует маршруты Fastify **вручную**, но **JSON-схемы запросов и ответов берёт из сгенерированного `openapi.json`** (Fastify проверяет их встроенным ajv), а **TypeScript-типы backend генерирует тот же `@hey-api/openapi-ts`** — вторым выходом только с плагином типов. Соответствие ответов контракту дополнительно проверяют контрактные тесты (как `apps/backend/src/contract.test.ts`).

Решение принято в тикете карты «API-контракт на TypeSpec и модель ошибок» (GitHub issue #7).

## Considered Options

- **`fastify-openapi-glue`** — регистрирует маршруты и валидацию из OpenAPI автоматически, но это сторонний плагин без заявленной поддержки Fastify 5 (по исследованию стека); привязка к нему труднее обратима, чем ручная регистрация.
- **Полностью ручная валидация в коде** — дублирует ограничения контракта (длины, форматы, обязательность) и расходится с ним при изменениях.
- **`@typespec/http-server-js`** — серверный эмиттер TypeSpec в alpha-версиях (`docs/stack-research.md`).

## Consequences

- Ограничения полей (длины, `format: email`, обязательность) задаются один раз — в TypeSpec — и проверяются на backend через схемы из `openapi.json`; бизнес-проверки (обрезка пробелов, допустимый слот, пересечения, уникальность `id`) остаются в коде сервиса (ADR-0003, ADR-0004).
- `mise run codegen` получает второй выход `@hey-api/openapi-ts` для backend-типов; он хранится в Git, исключается из ESLint/Prettier так же, как SDK frontend, и входит в CI-проверку актуальности сгенерированного кода.
- Ответы на ошибку схемы должны приводиться к единому телу ошибки контракта (`{ code, message, fieldErrors? }`, код `VALIDATION_ERROR`, HTTP 400) — стандартный ответ Fastify на ошибку валидации нужно преобразовать.
- Маршрут, не описанный в контракте, или расхождение ответа с ним ловят контрактные тесты, а не сама регистрация — это цена отказа от автоматической регистрации маршрутов.
